## Confluence APIの挙動について

- `confluenceGetInlineComments` は **resolutionStatus が resolved のコメントも返す**（確認済み）
- ページにコメントが0件 = そのページには本当にインラインコメントが付いていない（解決済みも含めてゼロ）
- 122件の「仕様」ページのうち、コメントが付いていたのは約10ページ（8%程度）
  - 残りはコメントなし＝指摘なしでFIXされたか、Slack上のみで議論された
- **dangling** ステータスのコメント = アンカー先のテキストが編集で消えたが、コメント自体は残っている状態
